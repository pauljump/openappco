# Open AppCo project contract

Canonical root: `/Users/mini-home/projects/openappco`.
Owner repository and public home: https://github.com/pauljump/openappco.
This repo owns the public narrative, research methodology, and progress tracker. App code and miner remain in existing canonical roots. Issue labels carry public status, generated from Apple's state (never hand-edited); the status pipeline (App Store Connect → issues → `docs/apps.json`) is described in docs/WORKFLOW.md. The public site is https://openappco.com, static files in `docs/` published by GitHub Pages from main (custom domain via `docs/CNAME`, DNS in the Cloudflare openappco.com zone). Support/privacy pages live beside it. No Mini service or local build is needed. `slipway/` is a published copy of the canonical `/Users/mini-home/projects/slipway` (exported at commit d8e5cf0); never edit it here. Re-export with `rm -rf slipway && mkdir slipway && git -C ../slipway archive HEAD | tar -x -C slipway` after a Slipway commit passes its privacy check. See docs/RELEASE-CUTOVER.md before redirecting submitted app URLs.

Prune has an explicitly authorized development preview at `/prune/`, with support and privacy pages and a homepage entry. It keeps the Prune name, is free, and must say it is not yet on the App Store until Apple availability is verified. This preview is separate from the numbered, submitted-app status pipeline; it has no launch number or invented App Store link.
