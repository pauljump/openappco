# Moved: App Store submission kit

This kit grew into [Slipway](https://github.com/pauljump/slipway), a general workflow for taking
small iOS apps from idea to live in the App Store. Submission and App Review responses are
[stage 7](https://github.com/pauljump/slipway/blob/main/docs/stages/7-submit.md) and
[stage 8](https://github.com/pauljump/slipway/blob/main/docs/stages/8-review.md).
